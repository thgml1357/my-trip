번역 준비 (폴드7 · 아이폰)

🤖 갤럭시 폴드7 (요한)🍎 아이폰 (와이프)
어떤 언어를 받아야 하나요?대만은 중국어(만다린)를 쓰고 글자는 번체자(繁體)입니다. 언어를 고를 때 '중국어(번체)'나 '중국어(대만)'이 있으면 그것을, 없으면 그냥 '중국어'를 받으세요. '대만어(台語)'는 받을 필요 없습니다. 말소리(만다린)는 중국 본토와 같아서 통역도 '중국어'로 됩니다.
언제 하나요?언어팩은 수백 MB까지 될 수 있으니 출국 전 집 와이파이에서 받으세요. 받은 뒤 비행기 모드로 켜서 테스트하면, 현지에서 데이터가 안 될 때도 쓸 수 있는지 확인됩니다.

🤖 폴드7 ① 갤럭시 AI 언어팩 필수

폴드7에 들어 있는 통역(대화 통역), 실시간 통화 통역, 채팅 번역, 사진 속 글자 번역이 이 언어팩을 씁니다.

  1. 설정 → Galaxy AI로 들어갑니다.
  2. 통역(또는 '실시간 통역') 항목을 누르고, 안에 있는 언어팩 메뉴로 들어갑니다.
  3. 중국어와 한국어 옆의 다운로드 버튼을 누릅니다.
  4. 같은 화면이나 Galaxy AI 설정에 '기기에서만 데이터 처리' 옵션이 있으면 켜서 오프라인으로 되는지 확인해 보세요. 평소에는 꺼두셔도 됩니다.

※ 메뉴 이름과 위치는 소프트웨어 버전에 따라 조금 다를 수 있습니다. 설정 맨 위 검색창에 '언어팩'이나 '통역'을 검색하면 바로 찾을 수 있습니다.

폴드7에서 통역 쓰는 법

  • 대화 통역: 빠른 설정 패널(위에서 아래로 쓸어내리기)에 '통역' 버튼을 추가해 두면 바로 켤 수 있습니다. 한국어 ↔ 중국어를 고르고 말하면 번역해서 읽어줍니다.
  • 마주 보고 대화: 화면을 반쯤 접어 세우거나, 대화 모드에서 커버 화면에 상대방 쪽 번역을 띄우는 기능을 쓰면 상대가 바로 읽을 수 있습니다.
  • 통화 통역: 식당 예약 등으로 전화할 때 전화 앱의 통화 통역 기능을 켜면 통화 중에 번역됩니다.

🍎 아이폰 ① 애플 번역 언어 다운로드 필수

아이폰 기본 번역 앱, 카메라·사진의 글자 인식(라이브 텍스트) 번역이 이 언어를 씁니다.

  1. 설정 → 앱 → 번역으로 들어갑니다. (iOS 버전에 따라 설정 → 번역)
  2. 다운로드된 언어를 누르고 중국어(번체)(또는 '중국어(대만)')와 한국어 옆의 다운로드 버튼을 누릅니다.
  3. 같은 화면의 '기기 내 모드'를 켜면 인터넷 없이 번역되는지 확인할 수 있습니다.

※ 설정 검색창에 '번역'을 검색하면 바로 찾을 수 있습니다.

아이폰에서 쓰는 법

  • 메뉴판 비추기: 번역 앱 → 카메라 탭에서 메뉴판을 비추면 글자 위에 한국어가 덮여 보입니다.
  • 카메라 앱으로 바로: 카메라를 글자에 비추면 오른쪽 아래에 글자 인식 버튼이 나옵니다. 누르고 번역을 고르세요.
  • 찍어둔 사진: 사진 앱에서 사진을 열고 글자 인식 버튼 → 번역.
  • 대화: 번역 앱 → 대화 탭에서 한국어 ↔ 중국어로 말하면 번역해서 읽어줍니다. 화면을 상대에게 보여주는 모드도 있습니다.
  • 빠르게 켜기: 설정 → 제어 센터에 번역 버튼을 추가해 두면 바로 열 수 있습니다.

🤖🍎 ② 구글 번역 앱 + 오프라인 중국어 둘 다 필수

메뉴판·간판을 카메라로 비추면 바로 번역되는 기능이 가장 쓸모 있습니다.

  1. Google 번역을 설치하거나 업데이트합니다. (폴드7은 플레이스토어, 아이폰은 앱스토어)
  2. 앱 위쪽 언어 선택에서 중국어(번체) → 한국어로 맞춥니다.
  3. 언어 이름을 누르면 나오는 목록에서 중국어 옆의 다운로드(↓) 아이콘을 눌러 오프라인 언어를 받습니다. 한국어도 함께 받으세요.
    🤖 폴드7: 프로필 아이콘 → 설정 → '오프라인 번역 언어' · 🍎 아이폰: 프로필 아이콘 → 오프라인 언어에서도 받을 수 있습니다.
  4. 비행기 모드에서 카메라 → 실시간 번역이 되는지 확인합니다.

※ 오프라인에서는 글자·카메라 번역은 잘 되지만, 음성 번역은 인터넷이 있을 때가 더 정확합니다.

🤖🍎 ③ 파파고 추천

한국어 번역 품질이 자연스러워 메뉴 설명을 읽을 때 좋습니다. 이미지 번역으로 메뉴판 사진을 찍으면 글자 위에 한국어가 덮여 보입니다.

  1. 파파고 설치 → 언어를 중국어(번체) ↔ 한국어로 설정
  2. 앱 설정에 오프라인 번역 메뉴가 있으면 한국어-중국어 팩을 받아 두세요.

※ 파파고 이미지 번역은 인터넷이 필요할 수 있습니다. 데이터가 안 될 때는 ②의 구글 번역을 쓰세요.

④ 있으면 편한 것 선택

🤖 폴드7

  • 서클 투 서치: 아무 화면에서나 하단 네비게이션 바(홈)를 길게 누르고 글자에 동그라미 → '번역'. 인스타·구글 지도 리뷰의 중국어를 바로 번역할 때 좋습니다. 인터넷이 필요합니다.
  • 사진 속 글자 복사: 갤러리에서 사진을 열면 글자를 인식하는 버튼(T 모양)이 나옵니다. 누르면 글자를 복사하거나 번역할 수 있어, 낮에 찍은 메뉴판·안내문을 나중에 번역할 때 좋습니다.
  • 삼성 키보드에 중국어 추가: 설정 → 일반 → 삼성 키보드 설정 → 언어 및 입력 방식 → 언어 관리에서 中文(臺灣)을 추가하면 손글씨로 한자를 써서 검색할 수 있습니다. 키보드 안의 번역 버튼으로 한국어를 쳐서 중국어로 바꿔 보내는 것도 됩니다 (우버이츠 기사님께 메시지 보낼 때 유용).

🍎 아이폰

  • 구글 앱의 렌즈: 구글 앱(또는 구글 번역)에서 렌즈를 열어 글자를 비추면 번역됩니다. 갤럭시의 서클 투 서치와 비슷하게 쓸 수 있습니다. 인터넷이 필요합니다.
  • 중국어 키보드 추가: 설정 → 일반 → 키보드 → 키보드 → 새로운 키보드 추가 → 중국어(번체) → 필기를 고르면 손글씨로 한자를 써서 검색할 수 있습니다.
  • 메시지 번역: 한국어로 쓴 글을 번역 앱에 붙여넣어 중국어로 바꾼 뒤 복사해서 보내면 됩니다.

지도 오프라인 저장

① 구글 지도 오프라인 지도 필수

  1. 구글 지도 앱 오른쪽 위 프로필 사진 → 오프라인 지도
  2. 내 지도 선택 → 네모 칸을 움직여 타이베이 시내 전체(스린 야시장~융캉제)가 들어가게 맞춤 → 다운로드
  3. 같은 방법으로 지우펀·루이팡 쪽도 따로 하나 더 받기 (시내와 떨어져 있음)
  4. 오프라인 지도 설정(⚙)에서 'Wi-Fi에서만 다운로드'와 자동 업데이트를 켜두면 편합니다.
  5. 🍎 아이폰도 구글 지도 앱에서 똑같이 하면 됩니다. 두 폰 모두 받아두면 한 명 데이터가 끊겨도 괜찮습니다.
오프라인 지도로 되는 것과 안 되는 것지도 보기, 내 위치(GPS), 장소 검색, 자동차 길찾기는 됩니다. 대중교통·도보 길찾기, 실시간 버스 시간, 영업 여부, 리뷰는 인터넷이 있어야 합니다. 데이터가 끊겼을 때 "지금 어디 있지?"를 확인하는 비상용으로 생각하세요.

② MRT 노선도 저장 추천

  • 타이베이 MRT 공식 노선도 이미지를 휴대폰에 저장해 두면 인터넷 없이 볼 수 있습니다. 역에도 크게 붙어 있습니다.
  • 이 가이드의 장소 탭 지도도 인터넷 없이 보입니다. 파일을 휴대폰에 저장해 가세요.

🍎 애플 지도 오프라인 아이폰 선택

아이폰은 기본 지도 앱 → 프로필(오른쪽 위 또는 검색창 옆) → 오프라인 지도 → 새로운 지도 다운로드로 지역을 받을 수 있습니다. 애플 지도 오프라인은 도보 길찾기도 되는 편이라 구글 지도와 함께 받아두면 좋습니다. 지원 범위는 지역에 따라 다를 수 있습니다.

③ 완전 오프라인 지도 앱 선택

인터넷 없이 도보 길찾기까지 되는 앱을 원하시면 Organic Maps 같은 오프라인 지도 앱에서 대만 지도를 받아 두는 방법도 있습니다. 대부분은 구글 지도만으로 충분합니다.
